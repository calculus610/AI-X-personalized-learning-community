① 认识电机 · 智能小车的"腿"

直流减速电机

  • 典型：3–6V TT 减速电机，两轮驱动小车常用
  • 两根线接电源，正反接 = 正反转
  • 调速：PWM 脉宽调制，改变有效电压
  • 直接用主控 IO 驱动 ❌ 电流不够，会烧板
  • 必须用 电机驱动模块 TB6612FNG

TB6612FNG 驱动模块

  • 双通道 H 桥，同时驱动 2 路电机
  • 电源：VM（电机电源）· VCC（逻辑）· GND
  • 控制：AIN1/AIN2/PWMA、BIN1/BIN2/PWMB、STBY
  • 逻辑： IN1=1,IN2=0 正转 IN1=0,IN2=1 反转 IN1=IN2 刹车

② 认识 SG90 舵机

180° 舵机（角度型）

  • 内部有电位器 + 反馈电路，PWM 决定停留角度
  • 50Hz PWM，脉宽 0.5ms → 0°，2.5ms → 180°
  • Arduino：servo.write(angle)
  • 常用于机械臂、云台

360° 舵机（连续旋转型）

  • 去掉了限位与反馈，PWM 决定 方向 + 速度
  • write(90) 停，<90 反转，>90 正转
  • 可当"减速电机 + 驱动"一体来用
  • 常用于轻负载轮子、传送带

接线（三根线）

  • 红：+5V（不要用 3.3V，力气会不够）　棕/黑：GND　橙/黄：信号线
  • 建议舵机电源与主控 共 GND、单独走电源，避免复位

④ 让小车跑起来

把 TB6612 两路电机封装成"动作函数"，就得到了小车的运动库。

// 引脚以底板 J9 原理图为准
#define AIN1 D0
#define AIN2 D1
#define PWMA D6
#define BIN1 D2
#define BIN2 D3
#define PWMB D7
#define STBY D5

void motor(int in1,int in2,int pwmPin,int speed){
  digitalWrite(in1, speed >= 0);
  digitalWrite(in2, speed <  0);
  analogWrite(pwmPin, constrain(abs(speed), 0, 255));
}
void forward(int s){ motor(AIN1,AIN2,PWMA, s); motor(BIN1,BIN2,PWMB, s); }
void back   (int s){ motor(AIN1,AIN2,PWMA,-s); motor(BIN1,BIN2,PWMB,-s); }
void left   (int s){ motor(AIN1,AIN2,PWMA,-s); motor(BIN1,BIN2,PWMB, s); }
void right  (int s){ motor(AIN1,AIN2,PWMA, s); motor(BIN1,BIN2,PWMB,-s); }
void stopAll(){ motor(AIN1,AIN2,PWMA,0); motor(BIN1,BIN2,PWMB,0); }

void setup(){
  int pins[]={AIN1,AIN2,PWMA,BIN1,BIN2,PWMB,STBY};
  for(int p:pins) pinMode(p,OUTPUT);
  digitalWrite(STBY,HIGH);
}
void loop(){
  forward(180); delay(1000);
  right  (160); delay(400);
  left   (160); delay(400);
  back   (180); delay(800);
  stopAll();    delay(1000);
}

🎯 先在桌上悬空试轮子方向；确认无误再让小车落地跑，防止翻车。

🎮 蓝牙控制小车

ESP32-S3 板载 BLE 5.0，不用额外硬件，手机就是遥控器。
在上一节小车运动库的基础上，把 loop() 里的 delay 序列换成 BLE 回调，小车就能被手机指挥。

工作流程

  1. ESP32-S3 广播一个 BLE 服务（自定义 UUID）
  2. 手机 App 扫描 → 连接 → 发送字符
  3. ESP32 收到 'F'/'B'/'L'/'R'/'S'
  4. 解析后调用 forward/back/left/right/stopAll

关键概念

  • Service（服务）：一组功能的集合，用 UUID 标识
  • Characteristic（特征值）：具体的数据通道
  • Nordic UART Service：一个通用的"串口式"BLE 协议，多数 App 都支持

蓝牙小车 · 手机 App 选择

方案 A：Serial Bluetooth Terminal

  • 安卓免费，界面简单
  • 可自定义 5 个按钮，各发送指定字符
  • 推荐做入门 Demo

方案 B：nRF Connect

  • Nordic 官方，安卓/iOS 都有
  • 可直接查看 BLE 服务、特征值
  • 适合调试 UUID，观察数据流

方案 C：Dabble

  • 专门做遥控的 App
  • 自带虚拟摇杆 + 游戏手柄界面
  • 效果最"炫"，需配套库

蓝牙控制小车 · 完整代码

#include <BLEDevice.h>
#include <BLEServer.h>
#include <BLEUtils.h>
#include <BLE2902.h>

// —— 电机引脚（沿用底板 J9） —— //
#define AIN1 D0
#define AIN2 D1
#define PWMA D6
#define BIN1 D2
#define BIN2 D3
#define PWMB D7
#define STBY D5

// —— Nordic UART Service UUID（通用，App 都支持） —— //
#define SERVICE_UUID "6e400001-b5a3-f393-e0a9-e50e24dcca9e"
#define CHAR_RX_UUID "6e400002-b5a3-f393-e0a9-e50e24dcca9e"

void motor(int in1,int in2,int pwmPin,int speed){
  digitalWrite(in1, speed >= 0);
  digitalWrite(in2, speed <  0);
  analogWrite(pwmPin, constrain(abs(speed), 0, 255));
}
void forward(int s){ motor(AIN1,AIN2,PWMA, s); motor(BIN1,BIN2,PWMB, s); }
void back   (int s){ motor(AIN1,AIN2,PWMA,-s); motor(BIN1,BIN2,PWMB,-s); }
void left   (int s){ motor(AIN1,AIN2,PWMA,-s); motor(BIN1,BIN2,PWMB, s); }
void right  (int s){ motor(AIN1,AIN2,PWMA, s); motor(BIN1,BIN2,PWMB,-s); }
void stopAll(){ motor(AIN1,AIN2,PWMA,0); motor(BIN1,BIN2,PWMB,0); }

class RxCB: public BLECharacteristicCallbacks{
  void onWrite(BLECharacteristic* c) override{
    String v = c->getValue().c_str();
    Serial.print("Got: "); Serial.println(v);
    char cmd = v.length() ? v[0] : 'S';
    switch(cmd){
      case 'F': forward(200); break;
      case 'B': back   (200); break;
      case 'L': left   (180); break;
      case 'R': right  (180); break;
      default : stopAll();    break;
    }
  }
};

void setup(){
  Serial.begin(115200);
  int pins[]={AIN1,AIN2,PWMA,BIN1,BIN2,PWMB,STBY};
  for(int p:pins) pinMode(p,OUTPUT);
  digitalWrite(STBY,HIGH);

  BLEDevice::init("XIAO-CAR");                    // 蓝牙名字
  auto* svr = BLEDevice::createServer();
  auto* svc = svr->createService(SERVICE_UUID);
  auto* rx  = svc->createCharacteristic(
      CHAR_RX_UUID, BLECharacteristic::PROPERTY_WRITE);
  rx->setCallbacks(new RxCB());
  svc->start();
  svr->getAdvertising()->start();
  Serial.println("BLE ready, name = XIAO-CAR");
}
void loop(){ delay(10); }

蓝牙小车 · 操作步骤 & 常见坑

操作步骤

1
上传程序 → 串口打印 BLE ready, name = XIAO-CAR
2
手机安装 Serial Bluetooth Terminal
3
Devices → Bluetooth LE → 扫描 → 选择 XIAO-CAR
4
连接成功后进入终端，右下角有 M1–M5 快捷键
5
长按快捷键 → 编辑 → 分别设置为 F/B/L/R/S
6
点按钮 → 小车动起来 🎉

常见坑

  • ❗ 一定选 Bluetooth LE 模式（不是 Classic）
  • ❗ App 端发送记得关掉自动换行，或代码里 trim()
  • ❗ 电机不动？先单独跑电机 Demo 验证接线
  • ❗ 一动就重启 = 电池电压不够，用锂电或稳压模块
  • ❗ 只能连一台手机，换手机记得先断开

📡 超声波避障小车 · 原理

另一条主线：让小车"自己看得见前方"，遇到障碍物自动停下或转向，不需要手机遥控。

HC-SR04 超声波模块

  • 4 根线：VCC（5V）· GND · TRIG（触发） · ECHO（回声）
  • TRIG 发 10μs 高脉冲 → 模块发出 8 个 40kHz 声波
  • ECHO 回一个高电平，宽度 = 声波往返时间
  • 距离(cm) = 高电平时长(μs) ÷ 58
  • 量程：2 – 400 cm，精度 3mm

避障逻辑（简单版）

  1. 正前方测距
  2. > 30cm → 前进
  3. ≤ 30cm → 停车，随机左转或右转 500ms
  4. 循环

进阶版

  • 把超声波装在 SG90 舵机 云台上
  • 停车时舵机左右扫描，选空旷方向走
⚠️ 引脚提示：底板 D2/D3 已经被电机 B 通道占用，超声波接线请走飞线到空闲引脚 D8/D9。

📡 超声波避障小车 · 完整代码

// —— 电机引脚（沿用底板 J9） —— //
#define AIN1 D0
#define AIN2 D1
#define PWMA D6
#define BIN1 D2
#define BIN2 D3
#define PWMB D7
#define STBY D5

// —— 超声波（飞线到空闲引脚） —— //
#define TRIG D9
#define ECHO D8

void motor(int in1,int in2,int pwmPin,int speed){
  digitalWrite(in1, speed >= 0);
  digitalWrite(in2, speed <  0);
  analogWrite(pwmPin, constrain(abs(speed), 0, 255));
}
void forward(int s){ motor(AIN1,AIN2,PWMA, s); motor(BIN1,BIN2,PWMB, s); }
void back   (int s){ motor(AIN1,AIN2,PWMA,-s); motor(BIN1,BIN2,PWMB,-s); }
void left   (int s){ motor(AIN1,AIN2,PWMA,-s); motor(BIN1,BIN2,PWMB, s); }
void right  (int s){ motor(AIN1,AIN2,PWMA, s); motor(BIN1,BIN2,PWMB,-s); }
void stopAll(){ motor(AIN1,AIN2,PWMA,0); motor(BIN1,BIN2,PWMB,0); }

long readDistance(){
  digitalWrite(TRIG, LOW);  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH); delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  long t = pulseIn(ECHO, HIGH, 30000);   // 超时 30ms
  return t == 0 ? 400 : t / 58;          // cm，读不到当很远
}

void setup(){
  Serial.begin(115200);
  int mpins[]={AIN1,AIN2,PWMA,BIN1,BIN2,PWMB,STBY};
  for(int p:mpins) pinMode(p,OUTPUT);
  digitalWrite(STBY, HIGH);
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
}

void loop(){
  long d = readDistance();
  Serial.print("Distance: "); Serial.print(d); Serial.println(" cm");

  if(d > 30){
    forward(180);              // 前方开阔，前进
  } else {
    stopAll();   delay(200);
    back(180);   delay(300);   // 后退一点
    right(180);  delay(400);   // 右转躲避
    stopAll();   delay(100);
  }
  delay(50);
}

拓展 · Wi-Fi 联网

ESP32-S3 内置 Wi-Fi，先用最简单例子确认能上网。

#include <WiFi.h>
const char* ssid     = "YOUR_SSID";
const char* password = "YOUR_PASSWORD";

void setup(){
  Serial.begin(115200);
  WiFi.begin(ssid, password);
  Serial.print("Connecting");
  while(WiFi.status() != WL_CONNECTED){ Serial.print("."); delay(500); }
  Serial.println();
  Serial.print("IP address: ");
  Serial.println(WiFi.localIP());
}
void loop(){}
  • 看到串口打印的 IP 地址 = 联网成功
  • 手机 / 电脑和小车必须在同一个 Wi-Fi（否则打不开网页）
  • 不支持 5GHz，请用 2.4GHz 频段

拓展 · 摄像头 CameraWebServer 远程拍照

操作步骤

1
选 XIAO_ESP32S3，开启 PSRAM
2
File → Examples → ESP32 → Camera → CameraWebServer
3
把摄像头型号宏改为：
#define CAMERA_MODEL_XIAO_ESP32S3
4
填入 ssid / password
5
上传 → 打开串口监视器 115200
6
看到 Camera Ready! Use 'http://192.168.x.x'
7
浏览器打开该网址 → 点 Start Stream / Get Still 远程拍照 📸

常见坑

  • ❗ 一定要 Sense 版本，普通版无摄像头
  • ❗ 插好 FPC 排线，蓝色朝上
  • ❗ PSRAM 没开会一直重启
  • ❗ 电脑和 XIAO 必须同一 2.4GHz Wi-Fi
  • ❗ 首次上传：按住 BOOT 键再插 USB 进入下载模式
