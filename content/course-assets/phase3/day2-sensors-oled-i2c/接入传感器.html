    通讯协议

    I2C 通讯协议

    I2C 是嵌入式系统中最常用的设备间通信协议之一，仅需两根线就能让主控与多个外设通信。

    🔌

    SDA — 数据线

    双向数据线，主设备和从设备通过它收发数据。

    ⏱️

    SCL — 时钟线

    由主设备产生时钟信号，决定数据传输的节奏。

    👑

    主从关系

    ESP32 做主设备，传感器/屏幕做从设备。时钟由主设备控制。

    🏷️

    设备地址

    每个从设备有唯一 7 位地址。ESP32 先发地址再传数据，总线上的设备只有地址匹配才会响应。

    ESP32
    主设备
    ━━ SDA ━━
    ━━ SCL ━━
    OLED
    地址 0x3C
    传感器
    地址 0x??
    设备 3
    地址 0x??
    🔝 上拉电阻 多条数据可以挂一条总线
    I2C 通讯流程：
    1. 主设备（ESP32）拉低 SDA，发出起始信号
    2. 主设备在 SCL 的每个时钟周期发送 1 位数据，先发送 7 位设备地址 + 1 位读写位
    3. 地址匹配的从设备回复 ACK 应答（拉低 SDA）
    4. 主设备继续发送或接收数据，每次 1 字节 + 1 位 ACK
    5. 主设备发送停止信号（SDA 由低变高），结束通信
    接线数量
    2 根
    最大设备数
    100+
    速度
    100k~400kHz
    通信方式
    同步串行

    analogWrite 的问题

    analogWrite() 频率固定在 1000Hz，无法变更音调。

    ✅ 推荐：LEDC（PWM 控制器）

    ledcSetup(4, 2000, 8);
    // 内部 PWM 通道 4，频率 2000Hz，占空比精度 8 位
    ledcAttachPin(BUZZER_PIN, 4);
    // 输出引脚 BUZZER_PIN，使用通道 4
    ledcWrite(4, 100);
    // PWM 占空比为 100/255
    距离传感器

    超声波传感器 CS100A

    📡

    工作原理

    发射 40kHz 超声波，测量声波遇障碍物返回的时间，计算距离。

    📏

    测距公式

    距离 = 时间 × 声速 ÷ 2

    🎯

    量程

    2cm ~ 400cm，精度约 0.3cm

    Trig / Echo 接口说明： CS100A 既不是 I2C，也不是单总线，而是采用专用的双引脚脉冲接口。
    • Trig（发射触发） — ESP32 向传感器发一个 10µs 的高电平脉冲，传感器收到后发射 40kHz 超声波
    • Echo（回波接收） — 传感器将回波时间编码为高电平脉宽，ESP32 用 pulseIn() 读取脉宽计算距离
    这种接口本质上就是两个普通 GPIO 在配合工作，不需要任何通信协议库。
    Trig
    发射信号
    → → → 🧱 ← ← ←
    Echo
    接收信号

    引脚连接

    CS100AESP32-S3
    VCC5V / 3.3V
    TrigGPIO1 (D0)
    EchoGPIO2 (D1)
    GNDGND

    示例代码

    1const int TRIG = 1;
    2const int ECHO = 2;
    3
    4void setup() {
    5  Serial.begin(115200);
    6  pinMode(TRIG, OUTPUT);
    7  pinMode(ECHO, INPUT);
    8}
    9
    10void loop() {
    11  digitalWrite(TRIG, LOW);
    12  delayMicroseconds(2);
    13  digitalWrite(TRIG, HIGH);
    14  delayMicroseconds(10);
    15  digitalWrite(TRIG, LOW);
    16
    17  long t = pulseIn(ECHO, HIGH); // μs
    18  float cm = t * 0.034 / 2;
    19  Serial.print(cm);
    20  Serial.println(" cm");
    21  delay(500);
    22}
