Environmental perception: plug-and-play machine senses

环境感知：机器感官即插即用

Students connect sensors, screens, cameras, microphones, LED strips, and Edge AI tools so hardware can sense and understand the environment.

Lecture introduction

中文课程简介

本课程主题是“环境感知：机器感官即插即用”。学生把不同硬件模块理解为机器的感官：温湿度传感器感知环境状态，超声波感知距离，摄像头形成视觉，麦克风形成听觉，OLED 和灯带让感知结果可见。

Students move from basic hardware input/output into plug-and-play machine senses. Each day adds a new sensing channel, then uses rules, displays, sensor fusion, or Edge AI to turn raw signals into environmental understanding.

Hardware checklist

  • ESP32-S3 or Arduino-compatible development board
  • LED, button, breadboard, jumper wires
  • DHT11 temperature/humidity sensor
  • 0.96 inch I2C OLED display
  • Ultrasonic ranging sensor
  • Seeed XIAO ESP32-S3 Sense or camera/microphone board
  • Addressable LED strip such as WS2812/NeoPixel

Software checklist

  • Arduino IDE installed
  • ESP32 board package installed
  • Serial Monitor works at 115200 baud
  • Libraries: DHT, Adafruit SSD1306, Adafruit GFX
  • Camera examples for your ESP32-S3 board
  • Edge Impulse account and exported Arduino libraries for advanced labs

How to use this folder

如何使用本文件夹

  1. Open this index.html first to understand the lecture structure.
  2. Read README.md for the overall learning path.
  3. Go to each day folder and follow the lab README files.
  4. Open each .ino file in Arduino IDE.
  5. Upload, observe, debug, and explain how hardware input becomes intelligent output.
  6. Submit final code, lab report, and evidence files in the outputs/ folder.
